# AI Lab — Interactive Micro-learning MVP

AI Lab is a two-week AI foundations investigation for Years 7–12.

## Learning design
Each lesson is broken into short missions with interactive checks and local autosave.

## Section videos
Lessons 1–9 begin with a Watch → Notice → Apply pattern. Lesson 10 is the final assessment/report section.

## Assessment Centre
Lesson 10 contains a year-differentiated final Assessment Centre for Years 7–12, including a future-interest activity, year-specific assessment prompt, automatically marked knowledge quiz, written investigation evidence, year-level rubric, Student Evidence formatted submission, copy and Print/Save PDF controls, and an AI Use Declaration.

## Deployment
This is a static browser app and can be deployed directly to Vercel. Student work is currently stored in browser localStorage, so this version is suitable for pilot/testing rather than high-stakes persistence across devices.
